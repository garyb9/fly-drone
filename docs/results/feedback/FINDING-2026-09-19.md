# P1 ascending/proprioceptive feedback — causal test (weak positive)

**Status:** recorded 2026-09-19. P1 is landed: body feedback is a declared, opt-in,
additive alternate bundle, and the causal silencing gate exists. The gate **passed** on a
single metric — silencing feedback measurably reduces locomotion — but it is a weak
effect and does **not** yet improve foraging or dodging.

- Bundle: `data/malecns-feedback` (`feedback = c1-ascending-v1`), generated by
  `scripts/make_feedback_bundle.py`
- Mapping: `docs/results/feedback/feedback-mappings.json`
- Adapter: `docs/results/adapter/adapter-feedback.json` (`declared-v1:d860482b7e3dab18`)
- Gate report: `docs/results/feedback/feedback-check.json`
- Command: `fly-drone feedback-check --episodes 50 --seconds 120 --level 3 --workers 6 --seed-base 1000`
- Runtime: 3 179 s. Teacher never in the loop (`teacher_in_behaviour_path = false`).

## What P1 adds

Three declared body→brain channels, injected each brain tick into annotated input cells
(the wiring is untouched):

| Channel       | Body signal                                  | Cells                                                      | Confidence |
| ------------- | -------------------------------------------- | ---------------------------------------------------------- | ---------- |
| `haltere_l/r` | body-frame yaw/roll rate                     | `AN07B037_a/b`, `AN06B009` (ascending)                     | low        |
| `flow_l/r`    | mean absolute luma change between eye frames | fixed 1-in-N subsample of T4/T5 (64/side)                  | medium     |
| `proprio_*`   | rotor lag `(commanded-actual)/MAX_RPM`       | `joint_*`/`load_*` chordotonal+campaniform (body-mappings) | low        |

The bundle is alternate (`bundle_hash = 8f88052c4bbb…`), so the canonical adapter and
every accepted actor are untouched; the canonical adapter is refused on it by the pin.

## Causal result (50 seeds)

Paired-bootstrap 95% interval of `intact − silenced`:

| Metric               | intact | silenced | 95% CI           | changed |
| -------------------- | -----: | -------: | ---------------- | ------- |
| `slow_fraction`      |  0.572 |    0.623 | [−0.097, −0.003] | ✅      |
| `beacons_per_min`    |  0.060 |    0.030 | [−0.030, 0.090]  | ❌      |
| `collisions_per_min` |  1.150 |    1.290 | [−0.340, 0.050]  | ❌      |

Feedback is causally present: with the loop closed the drone spends ~5 points less time
near-stationary, and the interval excludes zero. But the same channel does **not** move
beacons or collisions, so this is an effect on _movement_, not on _skill_. The ghost row
(beacons 0.14/min) is noise-level and not a dissociation.

## Interpretation

This is the first positive causal gate in the body-agnostic programme: the body can now
tell the brain what it is doing, and that signal changes behaviour. It validates the C1
plumbing (identity, alternate bundle, injection, silencing), not a behavioural claim.
The expected next gains — if any — need either the feedback to reach cells that can act
on it (P3 visual relay, better ascending targets) or the dynamics to stop washing the
signal out (P2).

Honest caveats: the effect is one metric at the threshold (`ci[1] = −0.003`); the cell
mappings are low-confidence candidate labels (spec §5); the drone analogue for
proprioception (rotor lag per limb) is declared, not anatomical.

## Reproduce

```bash
env -u PYTHONPATH .venv/bin/python scripts/make_feedback_bundle.py
env -u PYTHONPATH .venv/bin/fly-drone adapter-calibrate \
    --bundle data/malecns-feedback --output docs/results/adapter/adapter-feedback.json
env -u PYTHONPATH .venv/bin/fly-drone feedback-check \
    --output docs/results/feedback/feedback-check.json \
    --episodes 50 --seconds 120 --level 3 --workers 6 --seed-base 1000
```
