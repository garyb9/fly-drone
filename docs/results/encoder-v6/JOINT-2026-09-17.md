# Encoder v6 — M4 gated joint training: negative result (2026-09-17)

Companion to [`RESULTS-2026-09-16.md`](RESULTS-2026-09-16.md) (§7: the alternating encoder round) and
the plan [`2026-09-17-fly-drone-07-gated-joint-training.md`](../../superpowers/plans/2026-09-17-fly-drone-07-gated-joint-training.md).
All numbers are from the one pre-agreed 300k-frame run on 2026-09-17; `roam_eval.ACCEPTANCE` and the
E1/E2 bars are untouched. **The run was rejected and round 0 remains the best valid v6 pair.**

## 1. What M4 changed

One learner instead of two alternating frozen-partner rounds: a single critic, a single reward, and a
joint 820-dim action (816 encoder currents + 4 velocities). Both heads update every step; nothing is
frozen. Warm start: encoder = the clone (`learned-v6:01280e414169ff9c`), velocity head = the round-0
decoder. The predictor/auxiliary objective and the clone anchor stay on the encoder head. α is the
single dimension-scaled init (9.76e-5) over the joint action.

Artifacts: `runs/v6/joint/round1/` — `encoder.pt` (`learned-v6:6265d6d2b15286b1`), `decoder.json`
(export parity 3.0e-6), `validation.json`, `e1e2-fixed.json`.

the pair stopped foraging and turned into an unconditional dodger. E3 (G4) was therefore skipped.

## 3. The liveness gate is necessary but not sufficient

`scripts/encoder_liveness.py` never fired: the encoder's output stayed above the frame-mean-std
floors the whole way.

| frame | light std | loom std |
| --- | --- | --- |
| clone | 0.81 | 0.24 |
| 50k | 0.81 | 0.24 |
| 100k | 0.59 | 0.41 |
| 250k | 0.24 | 0.20 |
| floor | 0.10 | 0.08 |

The representation was still non-constant while it lost loom/motion selectivity: E1 union fell to
0.49 while liveness stayed ~2× the floor. **A variance floor cannot detect a representation that is
alive but semantically empty.** The E1 probe is the gate that catches this, and it must run before
any deployment claim.

## 4. Auto-α drifted

`ent_coef` rose from the scaled init 9.76e-5 to **0.048** by 207k frames. Over 820 dims the summed
entropy term can dominate the actor loss, and the run shows the predicted failure mode (handoff §O2):
the actor ends up driving exploration noise rather than the DN→velocity map. This is the opposite end
from the Task 11 collapse (where the entropy term was ~100× too strong), which suggests the
single-α-over-joint-action scheme is not stable at this dimension regardless of the init.

## 5. Deviations from the plan

- Anchor weight stayed `ANCHOR_WEIGHT = 0.5`; decision O4 (weaken to 0.1) was not applied. The anchor
  was active from the clone throughout, so this does not explain the failure.
- G4/E3 was skipped by rule (G1 already failed), so the joint vs bypass comparison was not run.

## 6. Decision

Per decision O3, revert to `runs/v6/round0`. M4 as specified fails on the first and only permitted
run; the alternating route (Task 11) is also exhausted. Both routes through "train the spatial
encoder with SAC under a learned decoder" now have a clean negative result. Options before spending
more compute — pick with the user:

1. **Per-head α (O2 fallback):** separate entropy coefficients for the 816-current head and the
   4-velocity head, so exploration noise cannot be traded across heads. Directly targets §4.
2. **Decouple the critic:** keep the encoder representation out of the actor's entropy path (train the
   velocity head against a frozen/anchored encoder, update the encoder only through the auxiliary
   predictive + E1-style objective rather than the joint actor loss).
3. **Freeze the encoder:** accept the clone representation and train only the decoder (no SAC on the
   encoder). This abandons the "encoder improves E1" goal but preserves the v6 pipeline for other
   work.
