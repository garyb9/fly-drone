## Caveat: the bypass dodges blindly

The bypass's high dodge is **not** a visual skill — it flails:

| controller | near dodge (visible) | near dodge (ghost) |
| --- | ---: | ---: |
| full pair | 0.21 | 0.28 |
| bypass | 0.92 | **0.85** |

A 0.85 ghost dodge means the bypass "dodges" with the eyes blinded, i.e. a constant erratic motion
that the dodge metric rewards (the same failure mode the v5 rounds 1–2 showed). It is nonetheless
not better on the full comparison, so the gate passes — but this is the reason the dodge metric must
always be read with its ghost control, and the reason G2 requires all three metrics, not dodge
alone.

**Note on fairness.** The full pair's decoder is DAgger-trained, while the bypass is SAC-trained;
the bypass is therefore not a like-for-like competitor. The gate is conservative (the bypass must
beat on beacons, collisions *and* dodge), so a false pass is unlikely; a false *fail* would need the
bypass to out-forage the pair, which it did not. Proceed to the decoder SAC round.
